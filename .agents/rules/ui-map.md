# UI Map Navigation

For visual UI requests, consult [`../../UI_MAP.md`](../../UI_MAP.md) before searching. Start from its file and symbol hints, verify the current code, and use a narrow `rg` query when a line range has drifted.

Update `UI_MAP.md` when a component moves, is renamed, or changes responsibility. Ordinary line movement alone does not require a map rewrite.
