# 🌐 SlimeVR Electron + React Web GUI

The standard cross-platform desktop GUI for SlimeVR, customized with Apple HIG vibrancy, Liquid Glass styling, and Quest Standalone telemetry HUD.

---

### ⚡ Key Highlights
* **Vite + React 18**: Complete web client with full SlimeVR web ecosystem.
* **Apple HIG Styling**: 4-tier vibrancy, concentric squircle cards, and tactile flight elevation scrubber.
* **Electron Power Blocker**: Configured with `powerSaveBlocker.start('prevent-app-suspension')`.

---

### 🚀 How to Run
Double-click:
`Launch Electron SlimeVR.command`

### 🛠️ How to Update & Rebuild
Run:
```bash
./build.sh
```
Or from the project root:
```bash
pnpm run build
```
