# Changelog

All notable changes are listed here. This project is in early development, so anything may change between versions.

## [0.3.0] - 2026-10-04 (early preview)

### Added
- Adaptive drift compensation and pose stability estimation for trackers.
- UDP connection registry and tracker recovery states.
- Redesigned desktop interface shell and Quest diagnostics.
- New server and interface tests.

### Changed
- Repository reorganised: developer docs under `docs/dev/`, launch scripts under `scripts/`.
- `solarxr-protocol` now points to the project's own fork, `SJ-SolarXR-Protocol`.

### Known limitations
- macOS is the only tested platform.
- No packaged installers yet.

## [0.2.0]
- Published macOS interface snapshot.
